# Task Manager API

A simple Flask API for managing tasks and projects. Built for a software quality assignment to generate a SonarQube report.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python app.py`
3. API runs on http://127.0.0.1:5000

## Endpoints

- Users: `/users`
- Projects: `/projects`
- Tasks: `/tasks`
- Comments: `/tasks/<id>/comments`
- Analytics: `/analytics/...`
